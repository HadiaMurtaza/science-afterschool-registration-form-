## About
A clean and user-friendly registration form for a Science Afterschool Program, designed using HTML and CSS.

## Features
- Student first and last name fields
- Grade and teacher information
- Guardian name fields
- Phone number input
- Allergy and special requirements section
- Terms and conditions checkbox
- Registration button
- Custom form styling

## Technologies Used
- HTML5
- CSS3

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open form2.html in your browser.
